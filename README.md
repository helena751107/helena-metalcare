# Helena MetalCare — 누나를 진짜로 알아가는 과정

> **조현병.** 누나가 평생 안고 산 병을, 내가 죽기 전에 진짜로 알아가려는 기록.
> MetalCare는 원래 MentalCare의 오타. 고치지 않고 살린다 — **금속(metal)처럼 강력한 하나의 기준을 찾는 돌봄(care)**.

## 무엇을 하나요

| 과정 | 내용 |
|------|------|
| **듣기** | 누나가 듣는 환청을 음성으로 재현 — "누나에겐 이렇게 들린다"를 실제 소리로 |
| **분석** | 누나가 먹는 약 분석 |
| **상담** | 실제 병원을 찾아가 전문의와 상담 |
| **미러링** | 영화 <뷰티풀 마인드>를 거울로 조현병을 봄 (각색의 한계를 명시하며) |
| **대본** | 조현병 환자를 대본에 설정 (직접 창작) |

## 이 레포의 성격

완성된 "멘탈케어 가이드"가 아니라 **"내가 알아가는 과정" 그 자체**다.
멈춘 결론이 아니라 움직이는 기록. (결과 복제가 아니라 사고 과정 재현)

## 지킬 것

- **누나 신원(이름·위치·사진)은 절대 노출하지 않는다.**
- 환청·약·증상은 "이해를 위한 기록"이지 선정적 전시가 아니다.
- **의료 단정 표현 금지** — "전문의 확인 필요"로 돌린다.
